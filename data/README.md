# Example Models

`.prism` files contain model specifications in the PRISM modelling language.
`.props` files contain properties that can be checked on the model.

## Directories

- **zenodo-examples/** — Benchmark models from the [Baier et al. (AAAI 2024) Zenodo artifact](https://zenodo.org/records/13738447), used in the thesis evaluation.
- **two_dice/, dining-philosophers/, pig-game/, ...** — Additional example models for testing and demonstration.
- **big-example/** — A larger ProFeat-based feature model (used for scalability testing).

See also `evaluation_corpus/` in the repository root for benchmark models with ground-truth annotations.
